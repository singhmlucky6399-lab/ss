Daily Expense Tracker — Android Setup Guide
==========================================

1. Quickest Way (Use directly on Android):
   - Extract this ZIP file on your phone.
   - Open "index.html" using Google Chrome (or any Android browser).
   - Your expenses, monthly income, and recurring bills are saved locally in your browser.

2. Install as an Android App Icon (PWA):
   - Upload this folder to any free static host (e.g., Netlify Drop or GitHub Pages).
   - Open the hosted link in Chrome on Android.
   - Tap the three-dot menu (⋮) -> "Install app" or "Add to Home screen".
   - It will launch full-screen from your home screen just like a native app.

3. Convert to an .APK file (Optional):
   - Once hosted, paste your URL into PWABuilder (https://www.pwabuilder.com) to generate a downloadable Android .apk package.
